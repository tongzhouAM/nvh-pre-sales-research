# 接触式传感器点位推荐指南

> 配套传感器：接触式传感器（压电陶瓷加速度计，剪切型结构，不锈钢壳体，M5 安装）
> 用途：售前调研流程 §2.4 的领域知识注入——为异音检测提供传感器布点的工程经验基线
> 使用方式：先根据目标产品类别查本指南的对应模板，再结合实时搜索验证的产品结构细节进行适配

---

## 一、通用布点原则

接触式传感器是压电式加速度计，通过机械耦合直接采集结构振动。布点遵循四条铁律：

| 原则 | 规则 | 反例 |
|------|------|------|
| **传递路径最短** | 传感器放在离异响源最近的刚性结构上 | 异响在齿轮啮合面，传感器却贴在变速箱远端支架 |
| **耦合刚性最好** | 优先金属→金属直接接触；塑料壳体必须加铝合金转接座 | 传感器直接粘在塑料壳体上（塑料阻尼吃掉高频） |
| **不干涉运动件** | 传感器及线缆不得触碰旋转/滑动/往复运动部件 | 线缆垂入齿轮啮合区或被叶片扫到 |
| **方向一致性** | 所有通道轴向对齐，否则跨通道特征不可比 | 通道1测Z向、通道2测X向，频谱形态无法对比 |

### 传感器选型决策

| 场景特征 | 推荐方案 | 原因 |
|---------|---------|------|
| 异响频率 >2kHz（齿轮啸叫、轴承、制动尖叫） | **接触式优先** | 高频结构振动在空气中衰减快，加速度计直接耦合 |
| 产线环境噪声 70-80dB(A) | **接触式唯一解** | 麦克风信噪比不足，接触式信噪比高 30-50dB |
| 异响频率 <500Hz + 需空间场分布（轰鸣、风噪） | 麦克风阵列 | 低频声场需要多点空间采样 |
| 旋转件无法贴传感器（转子、半轴） | 非接触：麦克风 + 阶次追踪 / 激光测振 | 扭振类异音可考虑编码器方案 |

### 模板 A · 空调出风口总成

| 属性 | 内容 |
|------|------|
| **典型异音** | 拨轮步进咔哒 / 齿条跳齿 / 阻尼脂干涩摩擦 / 卡扣 BSR / 叶片震颤 / 气流啸叫 |
| **关键频段** | 冲击 100-500Hz / 摩擦 500-2000Hz / 气流 2000-8000Hz |
| **异音来源** | 拨轮转轴-齿条啮合面、卡扣-仪表板安装界面、叶片轴-壳体轴承孔、风道法兰密封面 |

#### 点位推荐

| 优先级 | 编号 | 贴附位置 | 传感器方向 | 覆盖异音 | 推荐理由 |
|--------|------|---------|-----------|---------|---------|
| 🥇 P0 | #1 | 拨轮转轴安装座背面，或拨轮与风道壳体铰接处 | 垂直于拨轮运动平面（Z 向） | 拨轮步进咔哒、齿条跳齿、阻尼脂摩擦 | 拨轮是唯一运动机构，90% 投诉集中于此，信号信噪比最高 |
| 🥈 P0 | #2 | 出风口总成与仪表板/IP 骨架的卡扣固定点，优选上侧卡扣 | 垂直于卡扣接合面 | 装配松动 BSR、卡扣预紧不足共振 | 出风口→仪表板振动传递主路径，抓到整个总成的结构模态 |
| 🥉 P1 | #3 | 水平叶片联动杆轴端，或叶片旋转轴与壳体轴承孔配合处 | 径向（检测松动）/ 轴向（检测间隙） | 叶片震颤、轴孔间隙共振 | 叶片是次要运动件，双叶片各布一个更佳 |
| 🏅 P2 | #4 | 出风口总成与 HVAC 风管对接法兰面 | 沿气流方向（轴向） | 气流扰动壳体共振、密封海绵脱落啸叫 | 可选增强，4 通道时补充 |

#### 通道组合

```
传感器数量    推荐组合              适用条件
─────────────────────────────────────────────────
1 通道       #1 拨轮根部          最小可用方案，覆盖最痛投诉
2 通道       #1 + #2              运动机构 + 结构路径全覆盖（推荐）
4 通道       #1 + #2 + #3 + #4    全点位覆盖，支持异响来源定位
```

#### 特殊注意事项
- 塑料壳体必须用氰基丙烯酸酯快干胶粘接铝合金转接座，传感器磁吸/螺栓固定在转接座上——**禁止直接粘塑料**
- 传感器及线缆不得触碰拨轮、叶片等活动部件
- 线缆留 ≥50mm 振动余量，弯成 Ω 形释放应力
- 出风口件小结构紧凑，优先微型传感器头（≤10g）

### 模板 B · 齿轮箱/减速器

| 属性 | 内容 |
|------|------|
| **典型异音** | 齿轮啮合啸叫 (GMF Whine) / 齿轮敲击 (Rattle) / 轴承通过频率 (BPF) / 轴不对中 |
| **关键频段** | GMF 基频+谐波 300-13000Hz / Rattle 宽频 <500Hz / 轴承 300-3000Hz |
| **异音来源** | 齿轮副啮合面（定轴/行星）、输入/输出轴轴承座、差速器壳体 |

#### 点位推荐

| 优先级 | 编号 | 贴附位置 | 传感器方向 | 覆盖异音 | 推荐理由 |
|--------|------|---------|-----------|---------|---------|
| 🥇 P0 | #1 | 输入轴轴承座外端面（靠近电机侧） | 径向（垂直于轴承轴线） | GMF 啸叫、轴承通过频率、输入轴不对中 | 功率输入端振动能量最大，GMF 基频在此处幅值最高 |
| 🥈 P0 | #2 | 输出轴轴承座外端面（靠近负载侧） | 径向 | 差速器 GMF、输出端轴承、负载侧 Rattle | 输出端抓差速器啸叫和负载冲击，与 #1 形成输入-输出对比 |
| 🥉 P1 | #3 | 齿轮箱壳体中部（定轴级/行星级对应位置） | 径向 | 中间级齿轮啮合、壳体共振 | 多级齿轮箱时中间级啮合在两端信号弱 |
| 🏅 P2 | #4 | 箱体安装脚/悬置点 | 垂直于安装面 | 结构路径传递、箱体共振模态 | 抓到经悬置传递到相邻系统的振动，辅助路径诊断 |

#### 通道组合

```
传感器数量    推荐组合              适用条件
─────────────────────────────────────────────────
1 通道       #1 输入轴端           单级齿轮箱最小方案
2 通道       #1 + #2               输入-输出对比，差速器啮合全覆盖（推荐）
4 通道       #1 + #2 + #3 + #4     多级齿轮箱 + 路径诊断
```

#### 特殊注意事项
- 箱体多为铸铁/铝合金——磁吸底座可直接吸附，无需转接座
- 避免贴在加强筋和法兰边上（局部刚度高→振动幅值偏低→信噪比差）
- 电驱减速器（无发动机掩蔽）：高频 GMF >5000Hz 对耦合刚性要求更高，确保接触面无油膜/油漆
- 输入/输出轴轴向也可布传感器抓不对中特征（轴向振动在不对中时显著增大）

### 模板 C · 电机总成（驱动电机/PMSM/感应电机）

| 属性 | 内容 |
|------|------|
| **典型异音** | 电磁啸叫（槽谐波 f=k×Ns×f_rot）/ 轴承电蚀 / 转子不平衡 / PWM 载波啸叫 / 定子共振 |
| **关键频段** | 电磁阶次 500-5000Hz（与转速-槽数相关）/ PWM 载波 5-50kHz / 轴承 1-3kHz / 不平衡 f_rot |
| **异音来源** | 定子铁芯-壳体界面（电磁力径向辐射）、前后轴承座、转子偏心导致的非均匀气隙 |

#### 点位推荐

| 优先级 | 编号 | 贴附位置 | 传感器方向 | 覆盖异音 | 推荐理由 |
|--------|------|---------|-----------|---------|---------|
| 🥇 P0 | #1 | 电机壳体中部（定子铁芯对应位置，非加强筋区域） | 径向（垂直于电机轴线） | 电磁阶次啸叫、定子共振、转子偏心 2 倍频 | 定子径向电磁力直接辐射到壳体的主路径，电磁噪声信噪比最高 |
| 🥈 P0 | #2 | 前端盖轴承座外端面（靠近输出端） | 径向 | 轴承通过频率/电蚀、转子不平衡 f_rot | 输出端轴承负载最大，电蚀特征最早在此处出现 |
| 🥉 P1 | #3 | 后端盖轴承座外端面 | 径向 | 后轴承故障、轴向窜动 | 与 #2 前后对比可判断轴承故障侧 |
| 🏅 P2 | #4 | 电机安装脚/悬置支架 | 垂直于安装面 | 结构传递噪声、扭矩波动引起的壳体振动 | 评估电机振动对相邻系统的影响 |

#### 通道组合

```
传感器数量    推荐组合              适用条件
─────────────────────────────────────────────────
1 通道       #1 壳体中部径向        最小方案，覆盖电磁啸叫主路径
2 通道       #1 + #2               电磁 + 轴承全覆盖（推荐）
4 通道       #1 + #2 + #3 + #4     全点覆盖 + 路径传递评估
```

#### 特殊注意事项
- 避开壳体上的加强筋和散热翅片（局部刚度高→振动幅值衰减 6-12dB）
- SiC 逆变器电机的 PWM 载波 20-50kHz——采样率需 ≥128kHz 才能抓到载波边带
- 发卡绕组电机（集中绕组）的电磁噪声比分布绕组高 5-10dB，中壳点位信号更明显
- 转子偏心敏感——#1 采集时同时关注 f_rot 边带（动态偏心）和 2×f_rot（静态偏心）

### 模板 D · 轴承座/轴承端盖（独立轴承座或大型旋转机械）

| 属性 | 内容 |
|------|------|
| **典型异音** | 滚动体通过频率 (BPFI/BPFO/BSF) / 保持架撞击 / 润滑不良摩擦 / 轴电流电蚀 |
| **关键频段** | 滚动体通过 100-3000Hz / 电蚀 1-3kHz / 润滑不良 500-2000Hz（宽频升高） |
| **异音来源** | 内外圈滚道、滚动体-保持架界面、轴承端面（轴电流放电点） |

#### 点位推荐

| 优先级 | 编号 | 贴附位置 | 传感器方向 | 覆盖异音 | 推荐理由 |
|--------|------|---------|-----------|---------|---------|
| 🥇 P0 | #1 | 轴承座外端面（负载侧，即轴向推力方向） | 径向（垂直于轴） | BPFI/BPFO/BSF 全系列、电蚀 | 滚动体外圈通过频率在负载区幅值最大 |
| 🥈 P0 | #2 | 轴承座侧面（与 #1 同一轴承座，90° 正交） | 径向（与 #1 正交） | 滚动体通过频率冗余、调制特征分离 | 正交双通道帮助分离调制源（不平衡 vs 不对中） |
| 🥉 P1 | #3 | 轴承座轴向端面 | 轴向（平行于轴） | 不对中、轴向窜动、推力轴承故障 | 不对中特征在轴向信号中最明显 |
| 🏅 P2 | #4 | 相邻轴承座（如输入-输出端配对） | 径向 | 轴承间故障对比、传递路径交叉验证 | 对面轴承故障通过轴传递时，本端信号也可见 |

#### 通道组合

```
传感器数量    推荐组合              适用条件
─────────────────────────────────────────────────
1 通道       #1 径向（负载侧）      单轴承检测最小方案
2 通道       #1（负载侧径向）+ #3（轴向）  滚动体 + 不对中全覆盖
4 通道       #1 + #2 + #3 + (#4 远端)      精密诊断 + 双轴承对比
```

#### 特殊注意事项
- 轴承座越小，传感器质量影响越大——≤10g 微型传感器优于通用型（附加质量改变局部模态）
- 轴承外圈通过频率 (BPFO) = (n/2)×f_rot×[1-(d/D)cosφ]，其中 n=滚动体数、d=滚动体直径、D=节圆直径、φ=接触角
- 电蚀特征在包络谱中表现为 BPFI/BPFO 及其谐波，时间越长谐波越清晰
- 润滑不良在加速度频谱中表现为 500-2000Hz 宽带底噪整体抬高 6-12dB

### 模板 E · 压缩机（涡旋/活塞/螺杆）

| 属性 | 内容 |
|------|------|
| **典型异音** | 涡旋喘振 / 压缩腔压力脉动 / 驱动电机电磁啸叫 / 阀片撞击 / 吸排气脉动 / 管路共振 |
| **关键频段** | 喘振 1-5Hz（调制包络）/ 压力脉动 20-200Hz / 电机阶次 500-5000Hz / 阀片 500-3000Hz |
| **异音来源** | 动涡盘-静涡盘端面密封处 / 压缩腔 / 阀片-阀板冲击面 / 电机定子-壳体 / 吸排气口管路 |

#### 点位推荐

| 优先级 | 编号 | 贴附位置 | 传感器方向 | 覆盖异音 | 推荐理由 |
|--------|------|---------|-----------|---------|---------|
| 🥇 P0 | #1 | 压缩机壳体中部（涡旋压缩腔对应位置） | 径向 | 涡旋喘振调制、压力脉动、壳体共振 | 压缩腔压力波动直接辐射到壳体中部，是压缩机 NVH 的主信号 |
| 🥈 P0 | #2 | 电机侧端盖轴承座（电动压缩机） | 径向 | 电机电磁啸叫、轴承故障、转子不平衡 | 电动压缩机电机是主振源，电磁阶次与压缩脉动交叉调制 |
| 🥉 P1 | #3 | 排气口法兰或排气阀盖 | 轴向（沿气流方向） | 阀片撞击、排气脉动、管路共振 | 排气端抓阀片动作和脉动，与 #1 形成压缩-排气对比 |
| 🏅 P2 | #4 | 吸气管路靠近壳体接口处 | 轴向（沿管路） | 吸气脉动、制冷剂流动噪声 | 可选——冷媒音（咕噜声）在吸气端更明显 |

#### 通道组合

```
传感器数量    推荐组合              适用条件
─────────────────────────────────────────────────
1 通道       #1 壳体中部           覆盖主压缩噪声
2 通道       #1 + #2（电动）/ #1 + #3（机械）    壳体 + 振源/排气全覆盖
4 通道       #1 + #2 + #3 + #4      全脉动路径 + 电机 + 管路
```

#### 特殊注意事项
- 涡旋压缩机动静盘分离力随转速变化——急降转速时喘振最明显（6000→2000rpm 触发）
- 热泵工况下壳体温度可达 60-80°C——传感器及线缆需耐温 ≥100°C，高温下磁吸力下降需改用螺栓固定
- 排气阀片撞击频率 = 转速 (rps) × 缸数，与压缩阶次重叠→需结合时域波形区分
- 冷媒流动噪声（咕噜声）在启动初期和除霜切换时最突出

### 模板 F · 制动器总成（盘式制动器）

| 属性 | 内容 |
|------|------|
| **典型异音** | 制动尖叫 (Squeal 1-16kHz) / 低速 Groan (20-500Hz) / DTV 抖振 (8-15Hz) / 制动粉尘异响 |
| **关键频段** | 尖叫 1-16kHz / Groan 20-500Hz / 抖振 8-15Hz（制动力矩波动频率） |
| **异音来源** | 制动盘-摩擦片接触面 / 卡钳-制动盘模态耦合 / 卡钳支架-转向节安装面 / 活塞-摩擦片背板 |

#### 点位推荐

| 优先级 | 编号 | 贴附位置 | 传感器方向 | 覆盖异音 | 推荐理由 |
|--------|------|---------|-----------|---------|---------|
| 🥇 P0 | #1 | 卡钳壳体背面（远离活塞侧的外壳中心） | 径向（指向制动盘中心） | 制动尖叫、Groan、盘-片摩擦模态 | 卡钳是盘-片振动的第一接收体，离摩擦界面最近且不随盘转动 |
| 🥈 P0 | #2 | 转向节/卡钳支架安装点（卡钳与转向节螺栓固定处） | 径向（垂直于制动盘平面） | DTV 抖振、制动力矩波动传递 | DTV 引起的制动力矩波动经卡钳→转向节→悬架传递，此点位抓传递路径 |
| 🥉 P1 | #3 | 制动盘防尘罩 | 轴向 | 防尘罩共振、碎石撞击 | 防尘罩共振是常见的误报来源，单独监测便于排除 |
| 🏅 P2 | #4 | 摩擦片背板（通过磨损指示器开口粘贴） | 垂直于摩擦面 | 摩擦片自身模态、粘滑 (Stick-slip) | 直接抓摩擦片振动，但传感器在制动过程中受热剧烈（禁用标准加速度计） |

#### 通道组合

```
传感器数量    推荐组合              适用条件
─────────────────────────────────────────────────
1 通道       #1 卡钳壳体           最小方案，覆盖尖叫+Groan
2 通道       #1 + #2               摩擦界面 + 传递路径全覆盖（推荐）
4 通道       #1 + #2 + #3 + #4     需要区分制动噪声与防尘罩/其他干扰源时
```

#### 特殊注意事项
- 制动尖叫频率高（可达 16kHz）→ 采样率 ≥51.2kHz，加速度计谐振频率 ≥25kHz
- 制动时温度剧烈变化——传感器工作温度 ≥125°C，优先螺栓固定而非磁吸（高温退磁）
- 线缆用高温编织套管保护，远离制动盘（热辐射 + 飞溅异物）
- #4（摩擦片背板）仅建议在研发台架阶段使用，产线 EOL 不建议——高温+磨损导致传感器安装不可靠
- 制动尖叫的判定关键是有无模态重合——采集完需同时做盘/片/卡钳的 FRF 锤击测试交叉验证

### 模板 G · 座椅/滑轨/内饰运动件

| 属性 | 内容 |
|------|------|
| **典型异音** | 滑轨 Rattle（路面冲击）/ 滑轨 Squeak（干摩擦）/ 调节电机 Whirr（200-1500Hz）/ 骨架 Boom（25-35Hz）/ 发泡-蒙皮 Creak（温湿度敏感） |
| **关键频段** | Rattle 宽频 <500Hz / Squeak 100-1000Hz / 电机 200-1500Hz / 骨架共振 25-40Hz |
| **异音来源** | 滑轨-滑块间隙 / 调角器齿板-锁止销 / 电机-蜗轮蜗杆 / 发泡-蒙皮接触面 / 头枕杆-导套 |

#### 点位推荐

| 优先级 | 编号 | 贴附位置 | 传感器方向 | 覆盖异音 | 推荐理由 |
|--------|------|---------|-----------|---------|---------|
| 🥇 P0 | #1 | 上滑轨后端（靠近调角器侧），滑轨外侧面 | 垂向（路面激励主方向） | 滑轨 Rattle、调角器锁止冲击 | 滑轨间隙 Rattle 在垂向激励下最明显，后端靠近驾驶员重心 |
| 🥈 P0 | #2 | 座椅骨架侧板中部（钢管/冲压骨架） | 横向 | 骨架共振 Boom (25-35Hz)、骨架传导的滑轨振动 | 骨架是座椅的振动主干，抓到全部传导路径 |
| 🥉 P1 | #3 | 调节电机壳体（如为电动座椅） | 径向 | 电机作动 Whirr、蜗轮蜗杆啮合声 | 作动声品质评价，仅在电动座椅且关注电机噪声时需要 |
| 🏅 P2 | #4 | 头枕杆根部（插入导套处） | 横向（前后/左右各一） | 头枕杆 Rattle | 可选——空座状态下头枕杆是最大 Rattle 源，坐人后抑制明显 |

#### 通道组合

```
传感器数量    推荐组合              适用条件
─────────────────────────────────────────────────
1 通道       #1 上滑轨后端          最小方案，覆盖滑轨 Rattle（最高投诉比）
2 通道       #1 + #2               滑轨 + 骨架，Rattle + Boom 全覆盖（推荐）
4 通道       #1 + #2 + #3 + #4     电动座椅 + 头枕全检测
```

#### 特殊注意事项
- 座椅检测的关键变量是**人的状态**——空座/坐人/不同体重，模态和 Rattle 特征完全不同。测试时必须覆盖空座+标准假臀
- 滑轨间隙设计 0.1-0.3mm，磨损后 >0.5mm→Rattle 急剧恶化——可在时域波形中设定冲击阈值
- 发泡-蒙皮 Creak 是温湿度敏感——低温低湿季节最严重。产线 EOL 常温环境下可能漏检
- 座椅骨架多为钢管/冲压焊接件——磁吸底座可直接吸附
- 路面激励模拟：推荐用多轴振动台（MAST）而非单轴激振器——单轴激励无法复现真实 Rattle

### 模板 H · HVAC 鼓风机/风扇

| 属性 | 内容 |
|------|------|
| **典型异音** | 叶片通过频率 (BPF) 啸叫 / 动不平衡 / 轴承缺陷 / 电机 PWM 啸叫 / 蜗壳共振 |
| **关键频段** | BPF = n_blades×rps（50-500Hz）/ 不平衡 f_rot / 轴承 300-3000Hz / 蜗壳共振 100-1000Hz |
| **异音来源** | 叶轮-蜗壳气动界面 / 电机前后轴承 / 电机定子-壳体 / 蜗壳安装面 / 风门执行器 |

#### 点位推荐

| 优先级 | 编号 | 贴附位置 | 传感器方向 | 覆盖异音 | 推荐理由 |
|--------|------|---------|-----------|---------|---------|
| 🥇 P0 | #1 | 电机壳体后端盖（远离叶轮侧） | 径向 | 动不平衡 f_rot、轴承通过频率、电机电磁噪声 | 电机振源——鼓风机的机械振动根因都在电机端 |
| 🥈 P0 | #2 | 蜗壳外壁（叶轮轴向中心对应位置） | 径向（指向叶轮中心） | BPF 气动激励、蜗壳共振 | 叶轮气动力直接作用在蜗壳上，BPF 在此处信噪比最高 |
| 🥉 P1 | #3 | 鼓风机安装脚/减振橡胶 | 垂直于安装面 | 结构传递、隔振效果评估 | 鼓风机振动→HVAC 箱体→仪表板的传递路径监测 |
| 🏅 P2 | #4 | 风门执行器壳体 | 垂直于执行器运动方向 | 风门步进咔哒、执行器齿轮异响 | 可选——仅在关注风门执行器时需要 |

#### 通道组合

```
传感器数量    推荐组合              适用条件
─────────────────────────────────────────────────
1 通道       #1 电机后端盖          最小方案，覆盖机械振源
2 通道       #1 + #2               机械振源 + 气动激励全覆盖（推荐）
4 通道       #1 + #2 + #3 + #4     全监测 + 路径 + 风门
```

#### 特殊注意事项
- 蜗壳多为 PP/GF 塑料——必须粘接铝合金转接座，禁止直接粘传感器
- BPF 在变转速工况下阶次追踪更有效，定转速时容易被电机 f_rot 及其谐波掩盖
- 多档位风速→每种风速下 BPF 不同，建议覆盖全档位扫描
- 蜗壳共振判定：锤击蜗壳外壁测 FRF，找到共振峰后与工作时的 BPF 频谱对照，±10% 频带内即判定为共振风险

### 模板 I · 转向系统（EPS/转向柱/转向器）

| 属性 | 内容 |
|------|------|
| **典型异音** | EPS 蜗轮蜗杆啸叫 (300-1200Hz) / 万向节 Rattle / 齿条敲击 (宽频 <500Hz) / 转向柱摆振 (20-30Hz) / 中间轴沙沙声 |
| **关键频段** | EPS 啸叫 300-1200Hz / 齿条冲击 <500Hz / 摆振 20-30Hz / 万向节 100-500Hz |
| **异音来源** | 蜗轮蜗杆啮合面 / 齿条-小齿轮啮合面 / 万向节十字轴-轴承 / 转向柱轴承 / 齿条衬套 |

#### 点位推荐

| 优先级 | 编号 | 贴附位置 | 传感器方向 | 覆盖异音 | 推荐理由 |
|--------|------|---------|-----------|---------|---------|
| 🥇 P0 | #1 | EPS 电机-减速器壳体（蜗轮蜗杆级对应位置） | 径向（垂直于蜗杆轴线） | EPS 蜗轮蜗杆啸叫、电机 PWM 谐波 | 转向系统最核心的 NVH 源——蜗轮蜗杆啮合 300-1200Hz |
| 🥈 P0 | #2 | 齿条壳体靠近小齿轮侧（转向器输入轴端） | 径向（垂直于齿条方向） | 齿条敲击 (Rattle)、小齿轮-齿条啮合冲击 | 路面冲击经转向拉杆→齿条→小齿轮，此处抓冲击和啮合 |
| 🥉 P1 | #3 | 转向柱管柱中部（驾驶员侧，可触及区域） | 横向（垂直于管柱轴线） | 转向柱摆振 (20-30Hz)、万向节沙沙 | 管柱是振动传递到方向盘的最后一站，抓驾驶员体感 |
| 🏅 P2 | #4 | 中间轴万向节附近 | 轴向（沿中间轴） | 万向节十字轴冲击、相位角偏差导致的力波动 | 可选——仅在万向节角度 >10° 或存在转向力波动投诉时 |

#### 通道组合

```
传感器数量    推荐组合              适用条件
─────────────────────────────────────────────────
1 通道       #1 EPS 壳体            最小方案，覆盖 EPS 啸叫（电动转向核心）
2 通道       #1 + #2               EPS 啸叫 + 齿条冲击全覆盖（推荐）
4 通道       #1 + #2 + #3 + #4     全链路覆盖 + 传递路径 + 驾驶员感受
```

#### 特殊注意事项
- EPS 壳体多为铸铝——磁吸底座可直接吸附
- 转向系统检测的难点是**激励方式**——静置无异响 ≠ 行驶无异响。建议台架上用伺服电机模拟路面力输入（0-50Hz 随机 + 脉冲）
- EPS 啸叫与助力电流正相关——同步采集 CAN 总线的助力电流信号做关联分析
- 万向节相位角理想 90°±10°，偏差 >15°→转向力波动+中频沙沙声——此问题在接触式振动中表现为 2×转向轴转频调制
- R-EPS（齿条助力）与 C-EPS（管柱助力）的振源位置不同：R-EPS 以 #2 为主，#1 为辅；C-EPS 以 #1、#3 为主

## 三、安装与耦合速查

| 壳体材质 | 耦合方式 | 关键参数 |
|---------|---------|---------|
| 铸铁/铸铝/钢 | 磁吸底座直接吸附 | 磁吸力 ≥50N；表面粗糙度 Ra≤3.2μm |
| 铝合金（非磁性） | 氰基丙烯酸酯快干胶粘接转接座 + 螺栓/磁吸固定传感器 | 胶层厚度 0.05-0.1mm（越薄越好），固化时间 ≥30s |
| 塑料（PP/PA/PC/ABS） | 铝合金转接座 + 快干胶粘接 + 传感器固定 | 转接座质量 ≤5g；禁止传感器直接粘塑料 |
| 高温表面（>80°C） | 螺栓固定 + 高温胶（硅酸盐基） | 磁吸在 80°C 以上退磁；标准快干胶 >120°C 失效 |

### 线缆工艺
- 留 ≥50mm 振动余量，弯成 Ω 形释放应力——线缆张力会引入伪振动信号
- 线缆固定点距传感器 ≥30mm，用布基胶带或线夹固定
- 有电磁干扰环境用屏蔽双绞线，屏蔽层单端接地

### 传感器方向对齐
- 所有通道轴向统一（如全部 Z 向或全部径向），否则跨通道频谱形态不可比
- 标记每个传感器的安装方向，拍照存档——事后分析时方向记混是常见踩坑点

## 五、阶段 0 验证建议

> 本指南的所有点位推荐均为基于产品结构和振动传递路径的理论最优。部署前必须有阶段 0 验证。

| 步骤 | 内容 | 时长 |
|------|------|------|
| 1 | 按推荐点位安装传感器，用便携式采集套装同步采集 | 0.5 天 |
| 2 | 每种已知异音类型录制 ≥10 台 NG 样件 + ≥20 台 OK 样件 | 1-2 天 |
| 3 | 对比各点位的时频图信噪比、96 维语义特征分离度 | 0.5 天 |
| 4 | 输出最优通道组合方案，确认工装设计 | 0.5 天 |

有产品 3D 图纸时，可进一步做模态仿真（Ansys/HyperMesh）辅助选点——仿真预判各候选点位的频响函数 (FRF)，选择在所关注频段内传递率最高的位置。
