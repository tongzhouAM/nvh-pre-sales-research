## 零、异音术语标准体系（7 大类）

> 所有异音描述必须归入以下标准分类，使用统一英文术语。

| 类别 | 标准英文术语 | 特征描述 | 评价指标 |
|------|------------|---------|---------|
| **冲击类 Impact** | Knock / Clunk / Rattle / Thud / Click / Tick | 瞬态、非稳态；由间隙/松动/碰撞产生；与路面输入或操作动作强相关 | 峰值声压级(dB SPL)、冲击持续时间(ms)、冲击次数/km |
| **摩擦类 Friction** | Squeak / Squeal / Groan / Creak / Chirp | 稳态或间歇；由两接触面相对滑动（粘-滑）产生；温湿度敏感 | S&R 专项评价；μ-v曲线斜率；Stick-slip 频率 |
| **持续调制类 Tonal/Modulated** | Whine / Hum / Moan / Buzz / Drone / Howl | 与转速/频率强相关；阶次明显；掩蔽效应消失后更突出（纯电） | THD、阶次声压级(dB)、调制深度、Tonality(tu) |
| **气流/流体类 Aero/Fluid** | Hiss / Whoosh / Gurgle / Surge / Whistle | 宽带/高频；与流速/压差相关；车速依赖性强 | A计权声压级 dB(A)、感知响度(sone)、Sharpness(acum) |
| **振动感知类 Vibration** | Shimmy / Judder / Shudder / Harshness / Roughness | 振动体感为主；4–100Hz；方向盘/座椅/踏板可感知 | 加速度RMS(m/s²)、ISO 2631 振动暴露、Roughness(asper) |
| **低频结构类 Structural** | Boom / Thump / Rumble / Booming | 20–150Hz；车身/腔体共振耦合；驾驶舱声压明显 | 1/3倍频程声压级、声腔模态频率(Hz) |
| **热胀冷缩类 Thermal** | Thermal Creak / Thermal Tick / Hot Soak Click | 温度变化引发；热车后/停车后发作；日晒→铝/钢/塑料膨胀系数差 | 发作温度阈值(°C)；CTE 差值；接触界面 μ |

## 三-B、整车 NVH 8 层架构（自顶向下系统视角）

> 来源：NVH 完整梳理结构化表格 · 整车NVH架构 Sheet（204行）· 经交叉验证修正。
> 用途：售前场景中快速定位客户产品的 NVH 问题属于哪个系统层级，以及该层级的关键定量参数。

### 架构总览

| 层级 | 名称 | 核心内容 | 售前切入点 |
|------|------|---------|-----------|
| 第0层 | 整车级 NVH | 模态管理、TPA传递路径、声腔模态、密封完整性、振动剂量 | 整车厂客户：CQCC 对标、VDV 舒适性评价 |
| 第1层 | 动力总成 NVH | 发动机本体、变速箱、悬置与传动系统 | 发动机/变速箱 Tier1：EOL 下线检测、GMF 啸叫控制 |
| 第2层 | 底盘与行驶系统 NVH | 悬架、转向、制动、车轮轮胎 | 底盘件 Tier1：IBC 制动噪声、EPS 啸叫、轮胎空腔共鸣 |
| 第3层 | 车身与内饰 NVH | 白车身、车门、座椅、仪表板、天窗、S&R | 车身/内饰 Tier1：S&R 温变试验、接附点动刚度 |
| 第4层 | 空气动力 NVH | 风噪、风振、气动附件 | 整车厂：密封完整性是风噪 EOL 代理指标 |
| 第5层 | 新能源专项 NVH | 驱动电机、逆变器、减速器、电池、充电、热泵、ADAS | **售前主战场**：电驱啸叫/EOL/ANC |
| 第6层 | 主动控制 NVH | ANC、AVC、ESS/VSS、主动排气阀、智能阻尼 | GB/T 46098-2025 合规窗口 |
| 第7层 | 评价与测试 | 客观指标、主观评价、声品质、工况/环境覆盖 | 所有客户：EOL 判定标准选择 |

### 第0层关键定量参数（整车级）

| 参数 | 数值 | 工程含义 |
|------|------|---------|
| 白车身一阶弯曲模态 | **≥35Hz**（目标），下限 25Hz | <25Hz 与路面激励重叠→轰鸣 |
| 白车身一阶扭转模态 | 35–55Hz | 与弯曲模态间隔 ≥10% 或 3Hz |

| 簧下质量模态 | 10–18Hz；簧上 1–2Hz | 分离比 ≥1.4 |
| 驾驶舱声腔 | 纵向一阶 100–150Hz；横向 140–180Hz；垂向 180–220Hz | 与板件辐射频率重合→轰鸣 |
| 关键接附点动刚度 | 前副车架 >5,000 N/mm@100Hz；排气吊钩 >1,000 N/mm@200Hz；后塔顶 >8,000 N/mm@150Hz | 不足→底盘放大量 +3–10dB |

| 目标级联 (Target Cascading) | 整车→路径级→子系统级→部件级 | EOL 参考件对比法+SPC 验证级联链路一致性 |

## 三-C、EOL 下线检测方法分类

| 检测方式 | 典型设备/手段 | 适用零部件 | 判定指标 | 售前关注点 |
|---------|-------------|-----------|---------|-----------|
| 主观听声 | 熟练技术员+隔音室；转鼓/滚道路试 | 全部总成、整车下线 | 10 分制主观评分；通常 ≥7 分合格 | 效率低、一致性差→自动化替代需求 |
| 麦克风阵列 | 声相机(Noise Camera)；近场声全息(NAH)；声强探头 | 发动机舱、车身板件、内饰 | SWL 声功率级(dB)；辐射热点位置；传声损失 IL | 定位精准但成本高 |
| 加速度传感器 | 压电式加速度计；激光多普勒测振仪(LDV)；MEMS | 悬置、减振器、轴承、齿轮箱、电机壳体 | RMS(m/s²)；峰值；阶次幅值；FRF；相干函数 | 最常用，成本适中 |
