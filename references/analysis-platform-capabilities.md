# 分析平台能力-客户需求匹配矩阵

> 将客户异音问题映射到 分析平台平台的具体分析能力，支撑售前 Demo 设计和价值论证。

---

## 一、异音类型 → 分析平台分析能力映射

| 异音类型 | 分析目标 | 分析平台分析节点 | 关键参数 | 所需传感器 |
|---------|---------|---------------|---------|----------|
| 阶次啸叫 (Order Whine) | 识别阶次、跟踪幅值变化 | `order_analysis` | 阶次切片、转速范围、分辨率 | 转速传感器 + 麦克风/加速度计 |
| 阶次啸叫 | 阶次切片瀑布图 | `waterfall` / `colormap` | 频率范围、时间分辨率 | 同上 |
| 齿轮敲击 (Rattle) | 时域冲击检测 | `time_domain` | 触发阈值、窗长 | 加速度计（高采样率） |
| 齿轮敲击 | 包络分析 | `envelope_analysis` | 带通滤波器设置 | 加速度计 |
| 电磁噪声 (EM Noise) | 阶次-频率分离 | `order_analysis` + `fft` | 电机极对数/槽数对应阶次 | 电流 + 振动 + 麦克风 |
| 共振 (Resonance) | 模态参数识别 | `fft` / `waterfall` / `frf` | 频率分辨率、平均次数 | 力锤 + 加速度计（或激振器） |
| 摩擦声 (Squeak) | 时频分析定位 | `stft` / `wavelet` | 窗函数、重叠率 | 麦克风阵列或近距离麦克风 |
| 冲击/敲击 (Impact) | 峰值检测+统计分析 | `time_domain` + `statistics` | 阈值、最小间隔 | 加速度计 |
| 风噪/气动噪声 (Aero) | 1/n倍频程分析 | `octave` (1/1, 1/3, 1/12) | 计权方式(A/C/Z)、时间常数 | 麦克风 |
| 主观声品质 | 响度/尖锐度/粗糙度 | `loudness` / `sharpness` / `roughness` | 标准选择(DIN/ISO/ECMA) | 双耳麦克风/人工头 |
| 制动尖叫 (Brake Squeal) | 高频频谱+时频分析 | `fft` + `stft` | 频率范围(1000-16000Hz) | 麦克风 + 制动工况传感器 |
| BSR(嗡嗡/吱吱/咔嗒) | 异音检测+分类 | `time_domain` + `fft` + `stft` 组合 | 自适应阈值 | 麦克风阵列 |
| 声学定位 | 声源定位 | `beamforming` / `sound_source_localization` | 阵列几何参数 | 麦克风阵列 |
| 振动传递路径 | 传递路径分析 | `tpa` / `frf` | 参考点选择 | 多通道加速度计 |
| 运行变形分析 | ODS可视化 | `ods` | 测点几何坐标 | 多通道加速度计/激光测振 |
| 旋转机械状态 | 趋势分析+报警 | `rms` / `peak` / `crest_factor` + `trend` | ISO 10816 限值 | 加速度计 |
| 滤波预处理 | 去工频/去趋势/带通 | `iir_filter` / `fir_filter` / `weighting_filter` | 截止频率、滤波器类型 | 任意 |

## 二、按售前切入场景映射

### 场景 1：电驱啸叫 NVH 开发与下线检测（汽车）

**客户痛点**：电动车减速器/电机在特定转速段产生令人不适的啸叫，影响品牌声品质口碑

**分析平台应对方案**：

| 环节 | 分析平台能力 | 说明 |
|------|-----------|------|
| 开发阶段 | `order_analysis` + `waterfall` | 台架/路试数据溯源啸叫阶次 |
| 开发阶段 | `colormap` | 转速-频率-声压级三维展示 |
| 下线检测(EOL) | `order_analysis`（批量自动化） | 产线批量检测，自动判异 |
| 对比分析 | `datasource` 多数据源管理 | 不同批次、工况、竞品数据集中对比 |

**Demo 设计思路**：
- 拿一段电驱啸叫的路试数据（或仿真数据）
- 节点图：`[Data Source] → [Weighting Filter(A)] → [Order Analysis] → [Colormap/Waterfall]`
- 展示 3 步完成从原始数据到阶次切片图的流程
- **亮点**：一键切换不同阶次、拖拽对比不同工况

### 场景 2：内饰 BSR 测试与异音分类（汽车/家电）

**客户痛点**：仪表台/座椅/门板等内饰件在路试中产生 Squeak/Rattle，人工主观评价效率低、一致性差

**分析平台应对方案**：

| 环节 | 分析平台能力 | 说明 |
|------|-----------|------|
| 异音检测 | `stft` / `wavelet` | 时频域定位异音事件 |
| 特征提取 | `time_domain`（峰值/峭度/crest factor） | 自动提取异音事件特征 |
| 批量对比 | 多通道 + 多数据源 | 不同样件、不同路况对比 |
| 报告生成 | 一键导出 | 分析结果+图表一键导出 |

**Demo 设计思路**：
- 用一段含 BSR 事件的车内多通道录音
- 展示 STFT 定位异音 → 自动标记时间点 → 统计异音事件分布
- **亮点**：自动化 vs 人工主观评价的效率对比

### 场景 3：家电噪声合规测试与竞品对比（家电）

**客户痛点**：新产品需满足 GB 19606 噪声限值，研发阶段需快速验证多个方案的噪声表现

**分析平台应对方案**：

| 环节 | 分析平台能力 | 说明 |
|------|-----------|------|
| 声压级 | `sound_level` (SPL / Leq / Lpeak) | A/C/Z 计权，快/慢时间常数 |
| 倍频程 | `octave` (1/1, 1/3) | 合规测试常用 1/3 倍频程 |
| 心理声学 | `loudness` / `sharpness` | 声品质评价（消费者主观感受） |
| 对比分析 | 多数据源叠加 | 不同方案、竞品对比 |

**Demo 设计思路**：
- 用多台竞品 + 自研样机的消声室测试数据
- 节点图：`[Data] → [Weighting(A)] → [Octave(1/3)]` + `[Loudness]`
- 展示一套数据 → 1 分钟出倍频程图+响度对比
- **亮点**：竞品-自研一键对比，研发讨论会上直接看结论

### 场景 4：旋转机械状态监测与故障诊断（工业）

**客户痛点**：产线电机/泵/风机数量多，巡检效率低，希望从"定期检修"转向"预测性维护"

**分析平台应对方案**：

| 环节 | 分析平台能力 | 说明 |
|------|-----------|------|
| 振动监测 | `rms` / `peak` / `crest_factor` | ISO 10816 状态判定 |
| 故障诊断 | `fft` + `envelope_analysis` | 轴承特征频率、不对中、不平衡 |
| 趋势跟踪 | `trend` 图 | 长期数据趋势，提前预警 |
| 在线接入 | 数据源插件定制 | 接入 PLC/SCADA/MQTT 实时数据流 |

**Demo 设计思路**：
- 用一段轴承从正常→早期故障→严重故障的振动数据
- 展示 FFT 频谱中轴承特征频率从无到有、幅度从小到大
- **亮点**：从"听到异响才修" → "数据提前 2 周预警"

### 场景 5：3C 产品"听音"产线检测（3C 电子）

**客户痛点**：笔记本/手机/耳机下线前需检测异常噪声（风扇异响、扬声器杂音、线圈啸叫），人工听音效率低、标准不统一

**分析平台应对方案**：

| 环节 | 分析平台能力 | 说明 |
|------|-----------|------|
| 产线快速检测 | `fft` + `stft` + 阈值判定 | 消音箱自动化检测 |
| 异音分类 | 特征提取+模板匹配 | 区分正常与异常样本 |
| 数据追溯 | 数据源管理 + 标签 | 每台出厂产品的声学指纹存档 |
| batch 对比 | 多数据源批量分析 | 不同批次、产线的声学质量统计 |

**Demo 设计思路**：
- 用正常品和含异音品的消音箱录音
- 展示 FFT 对比 → 自动标记异常频段 → PASS/FAIL 判定
- **亮点**：产线节拍（每件几秒内完成）、数据可追溯

## 三、分析平台核心差异化优势（售前话术要点）

| 优势 | 说明 | 对应客户痛点 |
|------|------|------------|
| **零代码** | 拖拽节点+连线即可完成分析流程，无需 Python/MATLAB | NVH 工程师门槛高、人手少 |
| **可追溯** | 从原始数据到最终结论，全链路可回放可复现 | 分析结果说不清、团队间扯皮 |
| **协作** | 分析流程可分享、数据+流程+结论一体化 | 团队拆不开、人均效率低 |
| **可扩展** | 节点生态+插件商店，不是单机工具 | 买了工具用两年就过时 |
| **AI 驱动** | AI 辅助建图、自动标注、异常检测 | 海量数据处理不过来 |
| **多数据源** | 一个平台管理所有 NVH 数据，不做"文件搬运工" | 数据散落各台电脑 |
